## 🚀 Featured Projects

### 🧩 [ContextCarry](https://contextcarry.tech) — Cross-AI Context Portability SaaS
> **MERN · Gemini API · Chrome Extension MV3 · JWT · MongoDB Atlas**

Compress AI conversations into portable, provider-neutral **context capsules** — transferable across Claude, ChatGPT, and Gemini. Features a Chrome MV3 extension that auto-captures conversations, production-grade JWT auth (access/refresh tokens, bcrypt, rate limiting), admin analytics dashboard, voice-to-capsule pipeline, and capsule sharing via email.

---

### 🗺️ [UNMAPPED](https://github.com/umarahad2005/unmapped_mit_hackathon) — Hack-Nation Global AI Hackathon (MIT × World Bank)
> **Next.js · FastAPI · Python · Google Gemini API · Multi-Agent Architecture**

Built for 1,700+ global builders at the Hack-Nation Hackathon backed by MIT and the World Bank Group. UNMAPPED is an open, localizable infrastructure layer that turns invisible skills into real economic opportunities for youth in low- and middle-income countries — addressing 600M+ youth with unmapped skills globally.

- **Mirror Test Engine** — adaptive, swipe-based skill verification against O*NET & ESCO task descriptions
- **Contextual AI Readiness Lens** — recalibrates automation risk using local ITU & Global Findex data
- **Protocol Infrastructure** — NGO/government-ready, hot-swappable labor taxonomies and languages
